# AlteredBeast_Neff_2pose
"This patch enables end-of-level bosses to open their arms when shooting lightning bolts, just like in the arcade version! It works with the 'Altered Beast (USA, Europe).md' ROM (requires a checksum fix) and is also compatible with the 'ReToned' version."
